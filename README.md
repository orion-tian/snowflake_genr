# snowflake_genr

Maya tool for making simple snowflakes, specifically ones resembling dendrite and plate snowflakes. The user can control the number of main branches and sub-structure each snowflake has along with changing the paramaters of the sub-structures. There is also a random button that randomizes all the paramaters of the snowflake to get some interesting resuts. 

For dendrites, users can control the number of main branches along with how many sub-branches each main branch has. For each sub-branch, they can also specify its position along the main branch, its length, and its angle. For plates, users similarly control the number of main branches and how many hexagon plates each main branch has. For each hexagon, they can specify its position, its radius, and its length. 

This was my second ever tool in Maya, where I increased the complexity from my previous tool by making a more complex geometry with greater control over its appearance. If I had more time, I would strive to let the tool be even more flexible with a general number of branches and sub-branches along with adding in recursive features such as sub-branches ontop of sub-branches and so on to create more realistic snowflakes.
